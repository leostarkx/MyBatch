# خطة التطوير المعمارية الشاملة لمنصة «دفعتي» 🏛️🚀

خطة هندسية تنفيذية تهدف إلى حل المشاكل الهيكلية وإعادة تنظيم المنصة بالكامل لتصبح في مصاف الأنظمة الأكاديمية العالمية، بالاعتماد على **تجزئة الكود، هندسة المحاور الموحدة (Hub Architecture)، وتحسين تجربة الهاتف الذكي بنسبة 100%**.

---

## مراجعة القرارات المؤكدة (User Confirmed Decisions)

> [!IMPORTANT]
> بناءً على إجاباتك، تم اعتماد خطة متكاملة تبدأ بتجزئة الكود، دمج التبويبات في محاور رئيسية مع تبويبات فرعية، وتحسين واجهات الموبايل والجداول.

* **القرار المعتمد 1: نطاق الخطة**: خطة شاملة تعالج تضخم الكود، ازدحام التبويبات، وتحسين تجربة الشاشات الصغيرة في آن واحد.
* **القرار المعتمد 2: بنية الملاحة الجديدة**: الانتقال من 14 تبويباً منفصلاً إلى **4 محاور تشغيلية ذكية (Smart Hubs)** مع تبويبات فرعية داخلية سلسة وسريعة.

---

## 1. المحور الأول: هندسة المحاور والملاحة المركّزة (Smart Hub Navigation)

### المشكلة الحالية:
وجود أكثر من 12 إلى 15 تبويباً بالقائمة الجانبية والشريط السفلي يسبب تشتتاً كبيراً للطالب ويزيد من وقت البحث عن المعلومة.

### الهيكلية الجديدة للمحاور (4 محاور رئيسية + الحساب الشخصي):

```
┌────────────────────────────────────────────────────────────────────────┐
│                        منصة دفعتي الأكاديمية                           │
├─────────────┬────────────────┬───────────────────┬─────────────────────┤
│ 🏠 الرئيسية  │ 📚 المركز      │ 📊 المسار         │ 💬 مجتمع            │
│             │    الدراسي     │    الأكاديمي      │    الدفعة           │
└─────────────┴───────┬────────┴─────────┬─────────┴──────────┬──────────┘
                      │                  │                    │
          ┌───────────┴──────────┐       │       ┌────────────┴───────────┐
          │ 📝 المهام والامتحانات│       │       │ 💬 شات الدفعة الجماعي  │
          │ 📚 الملازم والمحاضرات│       │       │ 📬 صندوق المقترحات     │
          │ ✍️ الملخصات المرئية  │       │       │ 🏆 لوحة المتصدرين      │
          └──────────────────────┘       │       │ 🚀 مشاريع التخرج       │
                                         │       └────────────────────────┘
                       ┌─────────────────┴─────────────────┐
                       │ 📈 كشوفات الدرجات والسعي (من 50)   │
                       │ 📋 الحضور والغياب (مع تقرير الـPDF)│
                       │ 🗓️ جدول المحاضرات والقاعات        │
                       └───────────────────────────────────┘
```

1. 🏠 **الرئيسية (Home Dashboard):**
   * بطاقة الترحيب والكود الجامعي للدفعة.
   * شريط العد التنازلي المباشر والفلاتر السريعة للمهام والامتحانات.
   * شريط التبليغات العاجلة والمثبتة.
   * كروت الوصول السريع للمحاضرة القادمة والمهام القريبة.

2. 📚 **المركز الدراسي (Study Hub):**
   * **تبويب 1: المهام والامتحانات 📝🎓:** متابعة الواجبات، الكويزات، وجدول الامتحانات مع إمكانية تحديد الإنجاز الفردي وإضافة المهام للممثل.
   * **تبويب 2: المحاضرات والملازم 📚:** استعراض الأقسام، بنوك الأسئلة، وملفات Drive وروابط التحميل.
   * **تبويب 3: الملخصات والملاحظات ✍️:** كتابة وتصفح الشروحات وقوانين المواد بالمحرر المرئي (WYSIWYG) مع الألوان والسبويلر.

3. 📊 **المسار الأكاديمي (Academic Path):**
   * **تبويب 1: الدرجات والسعي التراكمي 📊:** كشوفات السعي من 50، حاسبة الفاينال، ومعدلات الكويزات.
   * **تبويب 2: الحضور والغياب 📋:** تسجيل الحضور، إدارة الكروبات A/B/C/D، الاستثناءات، واستخراج تقارير PDF الرسمية المتطابقة بنسبة 100%.
   * **تبويب 3: جدول المحاضرات 🗓️:** الجدول الأسبوعي للمواد والقاعات وتوزيع الكروبات.

4. 💬 **مجتمع الدفعة (Community Hub):**
   * **تبويب 1: شات الدفعة 💬:** المحادثة الفورية، التفاعل، الردود، والصور.
   * **تبويب 2: صندوق المقترحات 📬:** إرسال المقترحات والتصويت عليها وإجابات الممثل.
   * **تبويب 3: لوحة المتصدرين 🏆:** تكريم الأوائل في السعي والحضور وتحفيز المنافسة.
   * **تبويب 4: مشاريع الدفعة 🚀:** كروبات العمل وتوزيع التكليفات.

5. 👤 **حسابي وإدارة الدفعة (Profile & Management):**
   * البطاقة الرقمية للطالب (Digital Student ID)، الإحصائيات، زر الرجوع الدائم، ونقل الممثلية وأدوات إدارة الدفعة (للـ Owner والممثل).

## 2. المحور الثاني: تجزئة ملف `App.tsx` المعماري (Code Modularization)

### المشكلة الحالية:
تجاوز ملف `App.tsx` حاجز 15,000 سطر يعيق الصيانة ويزيد احتمالية تداخل الحالات (State Collisions).

### خطة التجزئة الهندسية:
إنشاء مجلد `views/` وفصل الشاشات مع الحفاظ على البيانات المشتركة (State Management) دون كسر أي ربط حالي مع Firestore:

```
src/
├── views/
│   ├── HomeView.tsx           # واجهة الرئيسية، شريط العد التنازلي والتبليغات
│   ├── StudyHubView.tsx       # المركز الدراسي (المهام، الملازم، الملخصات)
│   ├── AcademicPathView.tsx   # المسار الأكاديمي (الدرجات، الحضور، الجدول)
│   ├── CommunityHubView.tsx   # مجتمع الدفعة (الشات، المقترحات، المتصدرين)
│   └── ProfileView.tsx        # الملف الشخصي والبطاقة الرقمية وإدارة الممثل
├── components/                # المكونات الفرعية المشتركة (المحرر، المودالات، الشريط)
├── services/                  # خدمات Firebase والتخزين والإشعارات
└── App.tsx                    # نقطة الانطلاق الرئيسية (Routing & Providers & Layout)
```

**ضمانات الأمان:**
- عدم حذف أو فقدان أي دالة (مثل `handleSaveExam`, `handleToggleAssignmentDone`, `handleSaveGrade`).
- تمرير الخصائص (Props) والدوال بسلاسة ونظافة مع TypeScript Interfaces صارمة.

## 3. المحور الثالث: تحسين واجهات الهواتف الذكية (Mobile-First Polish)

### المشكلة الحالية:
الجداول العريضة (مثل كشوفات الحضور وسجل الدرجات التفصيلي) تتطلب تمريراً أفقياً مرهقاً على شاشات الموبايل.

### خطوات التحسين:
1. **بطاقات الأكورديون الذكية للهاتف (Responsive Accordion Cards):**
   * على شاشات الهواتف (< 768px): إخفاء الجداول المعقدة واستبدالها ببطاقات طلاب أنيقة تظهر اسم الطالب ومعدل السعي أو نسبة الحضور؛ وعند لمس البطاقة، تنسدل تفاصيل درجات الكويزات وسجل الغيابات بمرونة فائقة.
   * على الشاشات الكبيرة (Desktop): يظل الجدول العريض متاحاً بكامل تفاصيله وميزاته للطباعة والعرض.
2. **الشريط السفلي المريح للإبهام (Thumb-Zone Bottom Navigation):**
   * شريط ملاحة سفلي يحتوي على المحاور الأربعة الرئيسية + الملف الشخصي، مع شارات حمراء للإشعارات الجديدة وارتفاع لا يتجاوز 60px لعدم حجب مساحة الشاشة.
3. **تثبيت زر الرجوع (Sticky Header Navigation):**
   * شريط علوي خفيف وواضح يثبت زر الرجوع للقسم السابق عند فتح الملفات الشخصية أو التقارير.

## 4. خطة الاختبار والتحقق (Verification Plan)

1. **التحقق من تكامل الملاحة**: تجربة التنقل بين المحاور الأربعة والتأكد من فتح كافة التبويبات الفرعية بسلاسة.
2. **التحقق من وظائف البيانات**: فحص إضافة وتعديل الواجبات والامتحانات والدرجات وتسجيل الحضور دون أي خطأ.
3. **فحص شاشات الهواتف الذكية**: محاكاة الشاشات الصغيرة (iPhone / Android) للتأكد من مظهر بطاقات الأكورديون وسهولة اللمس والاستخدام.
4. **فحص البناء النهائي**: تنفيذ فحص التجميع واللينت (`compile_applet` و `lint_applet`) لضمان خلو المشروع من أي خطأ برمجي.

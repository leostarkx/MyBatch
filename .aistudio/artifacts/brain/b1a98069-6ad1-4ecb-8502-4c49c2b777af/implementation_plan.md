# دعم تنسيق وترتيب الأكواد البرمجية في المحرر المرئي (Code Blocks & Inline Code Support)

تطوير المحرر المرئي (`RichTextEditor`) وعارض الملخصات (`FormattedTextRenderer`) لتمكين الطلاب وممثلي الدفعة من كتابة وتنسيق الأكواد البرمجية بسلاسة مثل التنسيقات الاعتيادية (Bold/Italic)، مع دعم تمييز الألوان للغات التخصص الشائعة (C++, C, Python, Java, SQL)، ترقيم الأسطر، صندوق عرض داكن عصري، وزر نسخ سريع.

---

### User Review & Critical Decisions

> [!IMPORTANT] 
> بناءً على إجاباتك المؤكدة في مرحلة الاستيضاح، تم اعتماد التالي:

- **Confirmed Decision 1 (طريقة التنسيق)**: إضافة خيار "كود" في شريط الأدوات يعمل طبيعياً مثل Bold و Italic؛ عند تحديد أي كلمة أو نص يمكن تحويله إلى كود مضمن (Inline Code)، أو تحويل الفقرات المحددة إلى كتلة برمجية كاملة (Code Block).
- **Confirmed Decision 2 (اللغات البرمجية المدعومة)**: تركيز خاص ومتقدم على لغات المقررات الدراسية لطلبة تقنية المعلومات والهندسة (`C++`، `C`، `Python`، `Java`، `SQL`) مع دعم عام للغات الويب والبرمجة الأخرى (`JavaScript`، `C#`، `HTML/CSS`).
- **Confirmed Decision 3 (مظهر صناديق الكود)**: تصميم قالب داكن عصري (Modern Dark Slate) متكامل مع الهوية الأكاديمية للتطبيق، مزود بشريط علوي يحتوي على اسم اللغة، وزر للنسخ المباشر بضغطة زر مع ترقيم الأسطر ومحاذاة برمجية دقيقة من اليسار لليمين (LTR) لمنع تداخل النصوص العربية مع الكود.

---

## 1. Overview & Core Concept

- **What It Does**: يمنح المستخدم إمكانية كتابة وتنسيق الأكواد داخل المحاضرات والملخصات الدراسية. سواء كانت كلمة واحدة أو دالة داخل سطر نصي (`Inline Code`)، أو برنامجاً كاملاً (`Code Block`)، مع تلوين الكلمات المفتاحية والدوال والنصوص والأرقام والتعليقات بدقة واحترافية.
- **Target Audience**: طلبة وممثلو كليات الهندسة وعلوم الحاسوب وتقنية المعلومات الذين يشاركون شروحات لمواد البرمجة وهياكل البيانات وقواعد البيانات.
- **Key Value**: الحفاظ على بنية الكود البرمجي سليمة دون أن تتشوه باتجاه الكتابة العربي (RTL)، مع إبراز معاني الأكواد بالألوان لتسهيل الحفظ والمراجعة للامتحانات، وتوفير زر نسخ فوري لتجربة الكود على المترجم (Compiler).

---

## 2. User Experience & Visual Design

### Key User Flows

1. **كتابة كود ضمن السطر (Inline Code)**:
   - يحدد الطالب كلمة أو تعبير برمجي (مثل `int x = 10;` أو اسم دالة `cin >> n;`).
   - ينقر على أيقونة الكود `</>` في شريط الأدوات.
   - يتحول النص المحدد فوراً إلى نص برمجي بخط أحادي المسافة وخلفية داكنة خفيفة.

2. **إدراج كتلة برمجية متعددة الأسطر (Multi-line Code Block)**:
   - يحدد الطالب مقطع كود أو ينقر على زر الكود ويختار "كتلة كود برمجية".
   - تظهر قائمة منسدلة أنيقة لاختيار اللغة المستهدفة (`C++`, `C`, `Python`, `Java`, `SQL`, `Other`).
   - يُدرج الصندوق البرمجي الداكن مباشرة مع ترقيم الأسطر على اليسار ودعم الضغط على مفتاح `Tab` للمسافات البادئة البرمجية.

3. **معاينة وقراءة الملخصات (Reader / Study View)**:
   - في صفحة عرض الملخصات أو الاختبارات، يظهر صندوق الكود بتصميم احترافي:
     - شريط علوي أنيق باسم اللغة وشارة مميزة.
     - زر تفاعلي `نسخ الكود` مع تأثير وميض وتأكيد `تم النسخ!`.
     - شريط أرقام أسطر واضح وثابت.
     - تمييز لوني دقيق (Keywords بالبنفسجي/الأزرق، Strings بالأخضر، Comments بالرمادي الهادئ، Numbers بالبرتقالي).

### Visual Identity & Theme Tokens

- **Code Block Background**: تدرج رمادي داكن فاحم موحد (`#0f172a` إلى `#1e293b`) يوفر أقصى درجات التباين للعين أثناء الدراسة الليلية والنهارية.
- **Syntax Highlighting Palette**:
  - `Keywords` (if, else, while, for, class, struct, return): أرجواني/أزرق ساطع (`#818cf8` / `#60a5fa`).
  - `Types & Primitives` (int, float, double, void, string, bool, vector): سماوي ساطع (`#38bdf8`).
  - `Strings & Characters` ("...", '...'): زمردي نضر (`#34d399`).
  - `Comments` (// ..., /* ... */, # ...): رمادي فاتح مقروء (`#94a3b8`).
  - `Numbers & Constants` (123, 0.5, true, false, NULL): كهرماني ذهبي (`#fbbf24`).
  - `SQL Commands` (SELECT, FROM, WHERE, JOIN, INSERT, TABLE): وردي قرمزي (`#f472b6`).
- **Typography**: خط كود أحادي المسافة هندسي (`font-mono`, `ui-monospace`, `JetBrains Mono`, `Consolas`, `monospace`) مع حجم خط مريح `13px` وارتفاع سطر `1.6`.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: محرك تمييز الألوان خفيف ومستقل (Lightweight Fast Tokenizer vs Heavy Bundles)**:
  - *Chosen Approach*: إنشاء محرك تمييز ألوان مدمج فائق الخفة مخصص للغات المطلوبة (C++, C, Python, Java, SQL, JS) يعمل دون أي مكتبات خارجية ضخمة قد تبطئ تحميل التطبيق في العراق أو تسبب مشاكل أمان في بيئة المتصفح.
  - *Why*: سرعة استجابة فورية، صفر تأخير، ويعمل بسلاسة حتى في وضع عدم الاتصال (Offline / PWA).
  - *Alternatives Considered*: استيراد حزم ضخمة مثل Monaco Editor، والتي تزيد حجم الحزمة بعدة ميغابايتات وتثقل الهواتف الضعيفة.

- **Decision 2: عزل اتجاه النصوص البرمجية (Direction LTR Isolation)**:
  - *Chosen Approach*: فرض `dir="ltr"` و `text-align: left` و `unicode-bidi: embed` بشكل قطعي على جميع عناصر الأكواد.
  - *Why*: النصوص والرموز البرمجية مثل الأقواس `{}` والعمليات `<<` و `->` تتعرض للتشويه والقلب عند خلطها مع لغة عربية RTL ما لم يتم عزلها داخل حاوية LTR مستقلة.

## 4. Technical Architecture & Data Strategy

### Architecture & Component Flow

```
┌─────────────────────────────────────────────────────────────┐
│                      RichTextEditor                         │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                   Toolbar Ribbon                      │  │
│  │  [Bold] [Italic] ... [</> كود البرمجة ▾] [Quote] ... │  │
│  └──────────────────────────┬────────────────────────────┘  │
│                             │                               │
│            ┌────────────────┴────────────────┐              │
│            ▼                                 ▼              │
│   [Inline Code `...`]            [Code Block ▾]             │
│   (تنسيق فوري للكلمة)          (اختيار: C++, C, Python,     │
│                                  Java, SQL, كود عام)        │
│                                              │              │
│                                              ▼              │
│                                  ┌───────────────────────┐  │
│                                  │ <pre class="academic- │  │
│                                  │   code-block"         │  │
│                                  │   data-lang="cpp"     │  │
│                                  │   dir="ltr">          │  │
│                                  └───────────────────────┘  │
└─────────────────────────────┬───────────────────────────────┘
                              │
                              ▼ HTML Storage
┌─────────────────────────────────────────────────────────────┐
│                   FormattedTextRenderer                     │
│  ┌───────────────────────────────────────────────────────┐  │
│  │   CodeBlockRenderer Component                         │  │
│  │   - Language Badge Header ("C++", "Python", etc.)     │  │
│  │   - Quick Copy Action (navigator.clipboard)           │  │
│  │   - Line Numbering Rail (1, 2, 3...)                  │  │
│  │   - Syntax Tokenizer (Keywords, Types, Strings, etc.) │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### Planned File Enhancements

1. **`components/RichTextEditor.tsx`**:
   - إضافة أيقونة الكود `Code` مع قائمة اختيار ذكية: كود مضمن (Inline) أو كتلة كود كاملة مع اختيار اللغة.
   - دعم اختصار لوحة المفاتيح `Ctrl/Cmd + E` أو الزر المباشر للتنسيق البرمجي.
   - معالجة الضغط على مفتاح `Enter` و `Tab` داخل صناديق الكود لمنع الخروج غير المقصود ولإتاحة الترتيب البصري للأكواد.

2. **`components/FormattedTextRenderer.tsx`**:
   - ترقية معالجة الوسم `<pre><code class="...">` والنصوص البرمجية في وضع HTML ووضع Markdown.
   - ربط وتنسيق صناديق الكود بالقالب الداكن الجديد مع ترقيم الأسطر وزر النسخ السريع.

3. **`services/syntaxHighlighter.ts` (جديد)**:
   - وحدة خفيفة لمعالجة وتحليل الرموز البرمجية (Lexer / Tokenizer) للغات C++, C, Python, Java, SQL مع توليد عناصر Span ملونة بدقة.
